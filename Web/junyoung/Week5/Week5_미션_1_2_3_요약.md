## 미션 1. Protected Route를 활용하여 페이지 안전하게 보호하기

### 핵심 목표

로그인한 사용자만 접근할 수 있는 페이지를 `Protected Route`로 보호하는 미션입니다.

예를 들어 프리미엄 웹툰 페이지, 마이페이지, 회원 전용 페이지처럼 인증이 필요한 경로에 비로그인 사용자가 직접 URL을 입력해 접근하지 못하도록 막아야 합니다.

### 구현 내용

- Swagger 문서를 확인하여 토큰이 필요한 API와 연결된 페이지를 파악합니다.
- 인증이 필요한 페이지를 `Protected Route`로 감쌉니다.
- 로그인하지 않은 사용자가 보호된 페이지에 접근하면 로그인 페이지로 리다이렉트합니다.
- 로그인한 사용자는 원래 접근하려던 보호 페이지를 정상적으로 볼 수 있게 합니다.

### 체크 포인트

- 자물쇠가 걸린 API와 관련된 페이지가 보호되고 있는가?
- 토큰이 없을 때 보호 페이지 접근이 차단되는가?
- 비로그인 사용자가 로그인 페이지로 이동하는가?
- 로그인 후 보호 페이지 접근이 정상적으로 가능한가?

### 제출 기록

- 깃허브 주소
- 실행 영상

## 미션 2. Refresh Token을 활용하여 지속적인 로그인 유지하기

### 핵심 목표

Access Token이 만료되어도 Refresh Token으로 새로운 Access Token을 발급받아 사용자의 로그인 상태가 끊기지 않도록 만드는 미션입니다.

Access Token은 보통 짧은 유효 시간을 가지기 때문에, 만료될 때마다 사용자가 다시 로그인하게 만들면 사용성이 나빠집니다. Refresh Token을 이용해 자동 갱신 흐름을 구현해야 합니다.

### 구현 내용

- 제공된 문서를 참고하여 Refresh Token 실습용 서버 세팅을 완료합니다.
- API 요청 중 Access Token 만료 응답을 받으면 Axios 응답 인터셉터에서 감지합니다.
- Refresh Token을 이용해 새로운 Access Token을 요청합니다.
- 새 Access Token을 저장한 뒤, 실패했던 기존 요청을 다시 보냅니다.
- `_retry` 같은 플래그를 사용해 토큰 갱신 요청이 무한 반복되지 않도록 막습니다.

### 체크 포인트

- 서버 세팅이 완료되었는가?
- Access Token 만료 시 Refresh Token으로 재발급 요청을 보내는가?
- 새 Access Token을 저장하고 기존 요청을 재시도하는가?
- `_retry` 등을 통해 무한 루프를 방지하는가?
- Access Token 유효 시간을 짧게 설정해도 서비스 이용이 끊기지 않는가?

### 제출 기록

- 깃허브 주소

## 미션 3. Social Login Google 직접 구현해보기

### 핵심 목표

OAuth 2.0 기반의 Google Social Login을 직접 구현하는 미션입니다.

사용자가 구글 계정으로 로그인할 수 있도록 Google API Console 설정, Client ID 발급, Redirect URI 설정, 서버 환경변수 입력, 프론트엔드 로그인 흐름 연결을 진행해야 합니다.

### 구현 내용

- Google Login 실습 문서를 참고하여 Google API Console 설정을 완료합니다.
- Google OAuth Client ID를 발급받습니다.
- Redirect URI와 요청 권한(scope)을 정확히 설정합니다.
- 발급받은 Client ID 등 필요한 값을 서버 코드의 환경변수에 입력합니다.
- 프론트엔드에서 Google 로그인 버튼을 통해 백엔드의 Google 로그인 엔드포인트로 이동시킵니다.
- Google 인증 완료 후 콜백 흐름을 통해 로그인 상태가 만들어지는지 확인합니다.

### 체크 포인트

- Google API Console 설정이 완료되었는가?
- Client ID를 정상적으로 발급받았는가?
- Redirect URI가 서버와 Google Console 양쪽에서 일치하는가?
- 필요한 권한(scope)이 정확히 설정되었는가?
- Google 로그인 버튼 클릭 후 인증 플로우가 정상적으로 진행되는가?
- 로그인 성공 후 토큰 또는 로그인 상태가 정상적으로 저장되는가?

### 제출 기록

- 깃허브 주소
- 실행 영상
